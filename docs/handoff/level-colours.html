Mosaic · design update

The level badge uses a system-wide level colour, not the language accent.

On every surface that shows a CEFR level (thumbnail pill, in-video HUD badge), the badge is coloured by the level, identically across all five channels. Only the language accent (block, tesserae, counter) stays per-channel. This makes the level legible at browse size regardless of which channel a video is on.

The six level colours

A1A · purple · light
bg #B56AE7 · on #14121A
A2A · purple · deep
bg #581584 · on #FFFFFF
B1B · magenta · light
bg #E76ABD · on #14121A
B2B · magenta · deep
bg #84155F · on #FFFFFF
C1C · rose · light
bg #E76A83 · on #14121A
C2C · rose · deep
bg #84152B · on #FFFFFF

Each band (A/B/C) has one hue; the 1-level is the light tone (ink type + ink tessera), the 2-level is the deep tone (white type + white tessera).

What changes in the thumbnail template

The level pill currently fills with the language accent (e.g. #2E4FE0) and white type. Replace with the level colour above — background bg, type + tessera on — keyed by the video's level, the same value on every channel.

This removes the “German inverts the badge” rule. That rule existed because the gold accent failed contrast on white. Level colours carry their own on-colour, so no per-channel exception is needed — every channel shows the same level badge.
